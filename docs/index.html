    About This Tool

    This application predicts the occurrence of two major silkworm diseases using machine learning and public weather data.

    Diseases Monitored:
    • Virosis - Viral infections affecting silkworms
    • Bacteriosis - Bacterial infections
    Research Location:

    Ranchi, Jharkhand, India (23.3441°N, 85.3096°E)

    Live Forecast:

    The Flask backend fetches 7-day forecasts from Open-Meteo and NASA POWER, computes THI (NRC 1971), and returns daily risk levels via the RF+LR ensemble.
